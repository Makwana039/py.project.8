# NumPy Analyzer

## Project Overview

NumPy Analyzer is a menu-driven Python project built using the NumPy library. It allows users to create and manipulate 1D, 2D, and 3D arrays and perform various mathematical operations, array manipulations, searches, filters, and statistical calculations.

This project demonstrates practical applications of NumPy along with Python Object-Oriented Programming (OOP) concepts.

## Features

### 1. Create NumPy Arrays

* Create 1D arrays.
* Create 2D arrays.
* Create 3D arrays.
* Display array shape and dimensions.
* Validate user input and array dimensions.

### 2. Mathematical Operations

* Addition
* Subtraction
* Multiplication
* Division
* Dot Product
* Matrix Multiplication

### 3. Combine and Split Arrays

* Combine 1D arrays.
* Add rows to 2D arrays.
* Split arrays along a specified axis.
* Divide arrays into multiple parts.

### 4. Search, Sort, and Filter

* Search for specific elements.
* Sort elements in ascending order.
* Sort elements in descending order.
* Filter elements greater than a specified value.
* Display the indices of matching elements.

### 5. Aggregation and Statistics

* Calculate the sum.
* Calculate the mean.
* Calculate the median.
* Calculate standard deviation.
* Calculate variance.
* Find minimum and maximum values.
* Calculate percentiles.
* Calculate correlation coefficients.

## Technologies Used

* **Python** — Programming language
* **NumPy** — Numerical computing and array operations
* **Object-Oriented Programming (OOP)** — Classes, objects, encapsulation, class methods, and static methods

## Installation

### Step 1: Install Python

Download and install Python from the official website:

https://www.python.org/downloads/

### Step 2: Install NumPy

Open your terminal or command prompt and run:

```bash
pip install numpy
```

### Step 3: Download or Clone the Project

Clone the repository using:

```bash
git clone YOUR_REPOSITORY_URL
```

Alternatively, download the project files to your computer.

### Step 4: Run the Program

Navigate to the project folder and execute:

```bash
python main.py
```

## How to Use

1. Run the Python program.
2. Select an option from the main menu.
3. Create a NumPy array by choosing its dimensions.
4. Enter the required numeric values.
5. Select an operation from the available menus.
6. View the results in the terminal.
7. Choose Exit when you finish.
